# Supported Chains on Castrum

The following chains are currently available in Castrum:

1. [Planq Network ](https://planq.network/)(Cosmos & EVM)
   1. Features: self-custody, staking, governance, transactions
2. [Noble](https://www.nobleassets.xyz/) (Cosmos)
   1. Features: self-custody, staking, governance, transactions
3. [Osmosis](https://osmosis.zone/) (Cosmos)
   1. Features: self-custody, staking, governance, transactions
4. [Archway](https://archway.io/) (Cosmos)
   1. Features: self-custody, staking, governance, transactions
5. [Ethereum ](https://ethereum.org/en/)(EVM)
   1. Features: self-custody, transactions
6. [Polygon ](https://polygon.technology/)(EVM)
   1. Features: self-custody, transactions
7. [Binance smart chain ](https://www.bnbchain.org/en/bnb-smart-chain)(EVM)
   1. Features: self-custody, transactions
